# 1.3 界面导览

所有东西都在**http://localhost:17000**，桌面窗口和浏览器里是同一套界面。左边的侧边栏就是整个产品，顺序就是你配置它的顺序：先是Agent，再是它们背后的模型，然后是它们要过的那道关卡，接着是它们跑了什么、花了多少，设置放最后。

[![Casbin Gateway](https://cdn.casbin.org/img/casbin-gateway.gif)](https://cdn.casbin.org/img/casbin-gateway.gif)

带标签页或分节的页面，会把这些标签和小节也挂进侧边栏，所以侧栏可以直接落到测试用例、MCP服务器或安全设置上，而不是只能落到那一页的顶部。

## 导航

- **⌘K**或**Ctrl+K**在当前页面上打开搜索框：所有页面按名字搜，本机的每个Agent和每个供应商也在里面。三十个供应商里找一个，不用翻列表。
- **面包屑**会说明当前页面和页内小节，用的是和侧边栏同一棵树。
- 顶栏可以切换亮色/暗色、三套配色（**Amber & Ink**、**Terminal**、**Indigo**），以及中英文。

## 右上角的版本

右上角是当前运行的版本和构建日期；当已发布的版本更新时，会显示**新**。点开再按**立即升级**就能原地升级，见[5.5 升级、停止与卸载](../5-operations/5.5-lifecycle.md)。

## Agent是从哪来的

Agent是通过读**Gateway所在这台机器**的用户账户、主目录和安装路径发现的。所以要把它跑在你想观察的那台机器上；容器里只能看到容器自己的文件系统（[5.4](../5-operations/5.4-docker.md)）。
