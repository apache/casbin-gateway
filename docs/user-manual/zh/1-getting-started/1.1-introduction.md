# 1.1 产品介绍

Casbin Gateway是一个跑在本机上的网关，面向这台机器上装的AI编码Agent。它把这些Agent找出来，列清它们各自带了什么，在它们和模型供应商之间放一个统一的入口，并记录它们做了什么、花了多少。

它跑在你要管的那台机器上。数据不外发：数据库就是可执行文件旁边的一个文件，界面默认只绑定`127.0.0.1`。

## 它解决什么

| 你想 | 对应的页面 |
| --- | --- |
| 知道本机装了哪些Agent、各自登录的是哪个账号、花了多少 | [Agent客户端](../2-agents/2.1-agents.md)、[用量](../4-governance/4.3-usage-and-pricing.md) |
| 安装、升级、回滚Agent本身 | [版本管理](../2-agents/2.2-versions.md) |
| 换一次API Key，而不是改八个配置文件 | [供应商](../3-providers/3.1-providers.md)、[路由](../3-providers/3.2-routing.md) |
| 让Codex跑在DeepSeek上，让Claude Code跑在Qwen上 | [路由](../3-providers/3.2-routing.md) |
| 弄清中转商到底有没有给你它卖的那个模型 | [真伪检测](../3-providers/3.4-authenticity.md) |
| 单独收掉某个Agent的终端权限，或某一个MCP服务器 | [权限](../4-governance/4.1-permissions.md) |
| 看到Agent发出去的完整请求，包括提示词和工具定义 | [LLM记录](../4-governance/4.2-llm-records.md) |
| 让API Key不落到Agent的配置文件里 | [路由](../3-providers/3.2-routing.md)、[连接](../2-agents/2.5-connections.md) |

## 整体结构

```
      本机上的Agent                Casbin Gateway              模型供应商
+------------------------+     +----------------------+     +------------------+
| Claude Code            |     | 权限（Casbin）        |     | OpenAI           |
| Codex CLI              |---->| 协议转换              |---->| Anthropic        |
| Gemini CLI、Cursor ... |     | 记录与用量            |     | DeepSeek、Kimi   |
+------------------------+     | 供应商密钥            |     +------------------+
            ^                  +----------------------+
            |  读它们的配置、会话记录、技能和MCP服务器
            +----------------- 同一台机器 -----------------
```

两半互相独立，任何一半单独用都成立：

- **代理这一半。**Agent指向Gateway之后，它的请求会被鉴权、按权限校验、按供应商说的那套API做转换、转发出去，然后落记录。供应商的Key在Gateway手里，Agent自始至终拿不到。
- **读取这一半。**Agent是通过读这台机器的用户目录、安装路径和会话记录发现的。这一半从第一次启动就能用，不需要配供应商，也不需要把任何流量接过来——这也是[用量](../4-governance/4.3-usage-and-pricing.md)能算上那些根本没走Gateway的请求的原因。

因为读取这一半靠的是本机的文件，所以Gateway必须跑在你要管的那台机器上。在容器里它只能看到容器自己的文件系统，什么也找不到，见[5.4 Docker与Podman](../5-operations/5.4-docker.md)。

## 每个Agent支持到什么程度

目前认得三十来个Agent，对每个的支持深度不一样。[README](../../../../README_zh.md#每个-agent-支持到什么程度)里的表格是当前的清单，逐列说明：

- **监控**——只读的审计记录：提示词、工具调用、权限询问。Agent做任何事都不会等Gateway，开了监控也不会改变任何回答。
- **供应商**——Gateway会按该Agent客户端自己的格式，把它的配置文件改写成指向绑定的供应商。不支持这一列的Agent，仍然可以用界面给出的环境变量接进来。
- **MCP·技能·提示词**——在Agent之间读取、对比、复制MCP服务器、技能和指令文件。
- **会话**——直接从Agent自己的会话记录里读对话和token用量。
- **安装**——Gateway用什么方式装它、升它、卸它：npm、brew、winget、微软商店、Agent自带的更新器，或厂商自己的安装命令。
