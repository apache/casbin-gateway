# 1.4 快速上手

五分钟，从装好到能读一个Agent的流量。

## 第0步——你已经有的

打开**Agent客户端**。本机装的每个Agent都在那儿，带着它登录的账号、它使用的供应商、以及它花了多少——只要它自己的会话记录能追溯到，就按天铺开最近一个月。

**用量**页同样已经有数据了，来源是同一批会话记录。这两页都不需要供应商、不需要Key、不需要接任何流量。如果你只是想知道本机这些Agent到底在烧多少钱，到这里就结束了。

## 第1步——加一个供应商

**供应商**→**新增**：

1. 选类型：**OpenAI兼容**或**Anthropic兼容**。
2. 粘贴厂商的基础URL和API Key。
3. 填上它提供的模型。

存之前Gateway会先探一次上游，从此[真伪检测](../3-providers/3.4-authenticity.md)会自动给它打分。

Agent用的是ChatGPT或Claude订阅、根本没有API Key？把**认证方式**设为**调用方自己的登录**，见[3.3](../3-providers/3.3-caller-login.md)。

## 第2步——把Agent指过去

**Agent客户端**→打开一个Agent→选中那个供应商。

- 对于Gateway认得其配置格式的Agent，**写入配置**会直接改它自己的配置文件。**预览**先把要写的内容原样给你看，**恢复**可以撤销。
- 其他Agent，复制页面上的环境变量片段，在带着这些变量的shell里启动它：

```bash
export ANTHROPIC_BASE_URL="http://localhost:17000/v1/agents/claude-code"
export ANTHROPIC_AUTH_TOKEN="cg-..."
```

这个token是**Gateway自己的中继令牌，不是厂商的Key**。Agent那个变量为空就不肯启动，而Gateway对上游用的是供应商的Key。

之后再换一个供应商，配置文件当场重写，所以从此切换只需要一次点击。

## 第3步——跑一次，然后读它发了什么

正常用这个Agent，然后打开**LLM记录**：它转发的每个请求都在里面——完整的system提示词、每一条消息和工具调用、模型看到的每个工具的schema，外加token和费用。

如果这不是你想留下的东西，**在接入Agent之前**就改：页面顶部的选择器有**关闭记录**、**只记录元数据**、**记录元数据和正文**三档（[4.2](../4-governance/4.2-llm-records.md)）。

## 第4步——决定这个Agent能做什么

**权限**→选中该Agent。四十来个工具开关，分六组，外加它可以用哪些模型、哪些供应商。关掉的工具会在请求离开这台机器之前被摘掉，模型压根看不到它（[4.1](../4-governance/4.1-permissions.md)）。
