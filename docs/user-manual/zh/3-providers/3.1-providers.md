# 3.1 供应商

一个供应商就是Gateway可以把Agent请求发过去的一个模型端点：官方厂商、中转商，或者跑在本机上的东西。**供应商**页就是它们的列表。

[![新增供应商](https://cdn.casbin.org/img/casbin-gateway-new-provider.png)](https://cdn.casbin.org/img/casbin-gateway-new-provider.png)

## 新增

**供应商**→**新增**：

| 字段 | 填什么 |
| --- | --- |
| **类型** | 这个端点说哪套API：OpenAI兼容还是Anthropic兼容 |
| **基础URL** | 厂商的端点，照它自己文档给的填 |
| **API Key** | Gateway用来认证的Key——没有Key的情况见[3.3](3.3-caller-login.md) |
| **模型** | 它提供的模型。留空则接受任意模型名 |
| **认证方式** | 用上面这个Key，或者**调用方自己的登录**（[3.3](3.3-caller-login.md)） |
| **上游接口** | Gateway调用它时用哪个端点。除非厂商另有说明，保持**按类型推断**即可 |

存之前Gateway会先测一遍这个端点，此后[真伪检测](3.4-authenticity.md)会自动给它打分。

有些厂商在自己页面上放了"添加此供应商"的按钮，可以跳过这张表单，见[3.5 导入配置与链接](3.5-import.md)。

## 类型不是限制

类型说的是**供应商**说哪套API，不是你的Agent必须说哪套。Gateway在四套API之间双向转换，所以一个OpenAI兼容的供应商完全可以服务Anthropic客户端（[3.2](3.2-routing.md)）。

也就是说，对大多数中转商，答案就是：它文档里写的那一套。

## 厂商同时提供Responses接口时

**上游接口**在新增表单的**高级**里，供应商自己的页面上也有。它决定Gateway往基础URL后面接哪个路径：`/chat/completions`、`/responses`还是`/v1/messages`。**按类型推断**给OpenAI兼容的供应商选第一个，给Anthropic的选最后一个，对绝大多数厂商都是对的。

如果这个端点同时也提供Responses接口，就把它设成**Responses**。有两个理由：

- Codex客户端本来就说这套。两头都是Responses时，请求原样转发，不必来回翻译两次，规范形式没建模的东西也就不会丢。
- 有些中转商在`/responses`上报的缓存命中比在`/chat/completions`上准。这样缓存数就按上游给的原样进入[LLM记录](../4-governance/4.2-llm-records.md)，按缓存价而不是完整输入价计费。

这个设置只影响Gateway发往上游的请求，Agent那边该说哪套还说哪套。

## 只要有端点就行

有四十来家厂商和网关是按名字认得的，其他任何说得通这两套API的东西，用法完全一样：

- **官方厂商**——OpenAI、Anthropic、Google Gemini、xAI、Mistral、Cohere、DeepSeek、月之暗面、智谱GLM、MiniMax、阶跃星辰、百川等等。
- **聚合平台**——OpenRouter、硅基流动、Together、Groq、Fireworks、Novita、PPIO、AiHubMix、302.AI、Vercel AI Gateway。
- **云厂商**——Bedrock类端点、阿里云百炼、火山引擎、腾讯云、百度、魔搭、NVIDIA NIM。
- **本地**——Ollama、LM Studio、vLLM、llama.cpp、LiteLLM。

## Key存在哪

存在Gateway自己的数据库里，就在这台机器上。有两件事值得做：

- `apiKeyEncryptionKey`用AES-256-GCM把供应商的API Key加密落盘（[5.1](../5-operations/5.1-settings.md)）。
- Key不会进记录：请求头根本不存，正文在落库前会被脱敏（[4.2](../4-governance/4.2-llm-records.md)）。

流量走Gateway的Agent压根拿不到Key——它拿到的是Gateway自己的中继令牌（[3.2](3.2-routing.md)）。

## 哪个Agent能用哪个供应商

按Agent设置，在**权限**页：任意供应商，或只允许你勾的那几个（[4.1](../4-governance/4.1-permissions.md)）。
