# 2.5 连接

**连接**是一份收录了42个应用的目录——GitHub与GitLab、Slack、飞书、钉钉与企业微信、Notion、Figma、Sentry、Kubernetes、MongoDB与各类SQL数据库、走IMAP/SMTP的邮箱、Stripe与支付宝、Firecrawl与Tavily、高德与百度地图、浏览器、本机的某个目录，还有更多。在这里连一次，勾上该拥有它的Agent，Gateway会把它写进这些Agent各自的配置文件。

一个连接就是一个MCP服务器，只不过凭据留在Gateway里，而不是留在每个Agent的文件里。

## 连接一个应用

1. 选应用。目录按分类分组——办公协同、文档知识、开发工具、专业服务、邮件服务、网盘存储、生活服务——默认是**全部**。
2. 填它要的东西。每个字段都写清了值从哪来：GitHub的个人访问令牌在Settings→Developer settings里生成，Notion要先建一个内部集成再把页面共享给它，飞书要自建应用的App ID和密钥，高德要选**Web服务**类型的Key而不是应用类型的。有些服务器（浏览器、目录）根本不需要凭据，只需要你指定目录或目标。
3. **装入哪些Agent**：勾选Agent。之后取消勾选，就会把这个服务器从那个Agent里撤掉。
4. **连接**。

之后卡片会显示**已连接**，以及装进了几个Agent。

连接成功后会立刻在后台**测试**一次，这是每个工具能有独立开关的前提——见下文。

**断开连接**会把它从所有写入过的Agent里移除，并忘掉凭据。

## 用登录代替粘贴令牌

有些应用不是复制密钥，而是点头授权——目录里目前有两个：**GitHub（OAuth应用）**和**飞书（登录授权）**。飞书这个尤其值得多走一步：Agent能碰到的范围会变成*你*能碰到的范围，而不是这个应用被批准的全部权限。

应用是你自己在厂商平台上注册的：

1. 对话框里会显示一个**回调地址**，原样复制。
2. 在厂商那边建一个OAuth应用，把回调地址填成它。
3. 把应用的**Client ID**和**Client Secret**填回对话框。
4. 点**去授权**。会打开厂商的页面，在那里同意，然后回来。

授权记录留在你们自己的组织里，有自己的审计轨迹，全程不涉及Gateway的任何密钥。令牌快过期时Gateway会在会话真正需要它的那一刻自动续期。

## 测试连接，以及测试是为了什么

**测试**会启动这个应用的服务器，问它提供哪些工具，然后关掉。它带来两件事：

- 你能在Agent真正用它**之前**知道凭据是否可用。失败时会原样引用服务器自己说的话，所以密钥写错、目录不存在会如实显示，而不是变成一次超时。
- 拿回来的工具清单会变成**每个工具一个权限开关**。没测过的连接只有整个应用一个开关；测过之后，你可以让应用开着但单独关掉某个工具，也可以让它关着但单独放行某个工具。见[4.1 权限](../4-governance/4.1-permissions.md)。

从npm安装的服务器首次运行要先下载，比较慢，这不是失败。

## 为什么凭据不在Agent的配置里

Gateway写进Agent配置的是*Gateway自己*，作为要运行的那个服务器，参数是**连接的名字**。Agent启动这个服务器时，Gateway通过本地回环把凭据取出来，只在这一次会话的生命周期内有效。

所以：

- token不会散落在`~/.claude.json`、`~/.codex/config.toml`以及另外八个Agent的对应文件里。
- 改一次凭据，所有装了这个连接的Agent一起变。
- Agent发的所有内容都经过Gateway，因此一次工具调用可以在执行前按该Agent的[权限](../4-governance/4.1-permissions.md)校验、执行后记录——连接产生的流量和Agent其他工具受同一套规则约束。

Gateway搬家或换端口时会重写这些配置项，所以升级之后连接不会悄悄失效。

**代价是**：Agent是*通过*Gateway访问已连接的应用的，所以Gateway没运行时连接不可用，Agent里那些服务器会启动失败。勾选Agent那一步的提示里就写了这一条。

连接和供应商一样会进[快照](../5-operations/5.3-backups.md)，快照带密钥时凭据也一起带走。把快照恢复到另一台机器上时，配置项会按*那台*机器的端口和程序路径重新写入。

## 哪些Agent能装

只有Gateway知道怎么写其MCP配置格式的Agent。如果页面提示没找到Agent，说明这台机器上一个都没装——清单见[README](../../../../README_zh.md#每个-agent-支持到什么程度)表格的**MCP**列。

## 连接和"技能、MCP与提示词"的区别

| | [技能、MCP与提示词](2.4-skills-mcp-prompts.md) | 连接 |
| --- | --- | --- |
| 能加什么 | 任意MCP服务器，粘贴它的JSON | 目录里收录的应用 |
| 凭据放哪 | 写进每个Agent自己的配置 | 留在Gateway里 |
