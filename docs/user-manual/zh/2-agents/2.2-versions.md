# 2.2 版本管理

**版本管理**把Gateway认得的每个Agent放进一张表：本机装的是哪个版本、它的包管理器发布的是哪个版本、两者是否一致。

[![版本管理](https://cdn.casbin.org/img/casbin-gateway-versions.png)](https://cdn.casbin.org/img/casbin-gateway-versions.png)

在Agent所在那一行上：

| 操作 | 效果 |
| --- | --- |
| **安装** | 用这台机器上已有的包管理器装上它 |
| **升级** | 升到它的包管理器发布的版本 |
| **回滚** | 退回该管理器仍在提供的任意旧版本——升级把东西搞坏时用 |
| **卸载** | 卸掉它，Agent自己的登录和历史原样保留 |

不管当初是怎么装的，都是一次点击。

## 每个Agent用什么方式装

Gateway用的就是这个Agent实际的分发渠道：

| 方式 | 例子 |
| --- | --- |
| `npm` | Claude Code、Codex CLI、Gemini CLI、Cline、Qwen Code、opencode |
| `brew` | Cursor、Windsurf、Zed、goose、Trae |
| `winget` | Claude Desktop、Kimi Code CLI、Crush、opencode Desktop |
| 微软**商店** | ChatGPT Desktop |
| **self**——Agent自带的更新器 | Codex CLI、Cursor Agent、Hermes Agent |
| **script**——厂商自己的安装命令 | Cursor Agent、Claude Code |

以安装程序形式装进来的应用，卸载时走它在Windows上注册的那个卸载程序。其余的是从厂商页面下载，这种Gateway只会告诉你去哪下，不会替你自动做。

## 执行过程中能看到什么

- **命令会先展示出来再执行**，这台机器上不会发生你没读过的事。
- 执行期间那一行上带着**进度**。
- 它打印的所有内容都在那一行上**一点即看**——装失败时，原因就在这里。

## 哪些装的东西该更新了

这张表同时也回答"这台机器上什么过期了"：Gateway把每个已安装版本和它的包管理器发布的版本比对，标出不一致的行。**Agent客户端**页的卡片上带同样的标记。
