# 2.1 Agent客户端

**Agent客户端**是首页。本机装的每个AI编码Agent都在这儿，一行四张卡片。

[![Agent客户端](https://cdn.casbin.org/img/casbin-gateway.gif)](https://cdn.casbin.org/img/casbin-gateway.gif)

每张卡片给出：

- 它登录的**账号**，
- 它使用的**供应商**，
- 它**花了多少**——只要它自己的会话记录能追溯到，就按天铺开最近一个月，
- 以及它**此刻是否在运行**。

本机没装的Agent也会列出来，方便直接从这一页装上。

## Agent是怎么找到的

Gateway会读**它自己所在这台机器**的用户账户、主目录和安装路径，覆盖安装程序写出的那些目录布局，也覆盖手动解包、放进PATH的情况。

要是某个Agent藏在两者都描述不了的地方，就直接指给它：**选择程序**可以浏览本机，把你挑中的程序作为一个独立的安装列出来，不移动也不修改任何东西。

这也是Gateway必须跑在目标机器上的原因——容器里它读的是容器自己的文件系统，什么都找不到（[5.4](../5-operations/5.4-docker.md)）。

## 启动与停止

**启动**和**停止**就在卡片上。从Gateway启动的Agent，和你自己启动的是同一份安装，Gateway只负责把它拉起来。

## 实例

**实例**是同一个Agent的额外副本，每个有**自己的状态目录**，因此各自登录各自的账号，并且可以同时运行——最常见的理由是开几个Claude Desktop，一个账号一个。

- **添加实例**新建一个。
- **移除实例**只是让Gateway忘掉它。状态目录和登录在里面的账号都留在磁盘上。

## Agent自己的页面

点开卡片是同样的信息的完整版，外加所有按Agent设置的东西：

| 区域 | 作用 | 章节 |
| --- | --- | --- |
| 供应商 | 把这个Agent绑到某个供应商，预览并写入它的配置 | [3.2](../3-providers/3.2-routing.md) |
| 权限 | 与权限页相同的那张卡片，只针对这个Agent | [4.1](../4-governance/4.1-permissions.md) |
| 监控 | 开启这个Agent的只读活动记录 | [2.3](2.3-monitoring.md) |
| 版本 | 当前版本，以及包管理器发布的版本 | [2.2](2.2-versions.md) |
| 会话与花费 | 它自己的会话记录，以及对应的费用 | [2.3](2.3-monitoring.md)、[4.3](../4-governance/4.3-usage-and-pricing.md) |
