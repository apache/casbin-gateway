# 2.4 技能、MCP与提示词

本机每个Agent的每一个技能、MCP服务器和指令文件，汇成一张表。三个标签页，一类一个。

[![技能](https://cdn.casbin.org/img/casbin-gateway-skills.png)](https://cdn.casbin.org/img/casbin-gateway-skills.png)

三者共用一页的原因：它们其实是同一个问题的三种问法——这个Agent带了什么，别的Agent是不是也带着。某个技能只装在一个Agent里、另一个没有，在这张表上就是一行里的一个空格。

## 技能

把技能装进一个或多个Agent，来源可以是：

- 一个**GitHub仓库**，
- 一个**`.zip`或`.tar.gz`**压缩包，
- 或本机的一个**文件夹**。

表格列出哪些Agent有它。点开可以阅读、复制到别的Agent，或者删除。

## MCP服务器

添加方式一样——直接粘贴那段写服务器的JSON，也就是各家"添加此服务器"的代码片段本来的格式。

多勾几个Agent，同一个服务器就会按各自的格式写进每个Agent自己的配置文件。

需要凭据的服务器（GitHub、Notion、飞书这类）建议走[连接](2.5-connections.md)：token留在Gateway里，而不是复制进每个Agent的配置文件。

## 提示词

Agent每次会话前都会读的那个指令文件——`CLAUDE.md`、`AGENTS.md`及其同类。可以在这里编辑、打开、删除，或者把一个Agent的复制给另一个。

## 在Agent之间复制

每一行是一个条目，每一列是一个Agent，所以整页只回答一个问题：这个Agent有而那个没有的是什么。所谓复制，就是勾上要加进去的Agent。

哪些Agent能接受这三类中的哪几类，见[README](../../../../README_zh.md#每个-agent-支持到什么程度)表格中的**MCP·技能·提示词**列。
