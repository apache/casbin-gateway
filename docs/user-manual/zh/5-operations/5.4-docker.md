# 5.4 Docker与Podman

**容器里看不到你机器上的Agent。**

Agent是靠读Gateway所在这台机器的主目录和安装路径发现的，而在容器里那就是容器自己的文件系统。所以**Agent客户端**、**技能、MCP与提示词**和Agent监控在那里都是空的——页面会直说，而不是假装什么都没装。

不依赖宿主机的部分照常工作：**供应商**、**真伪检测**和**LLM记录**。

所以：想观察哪台机器上的Agent，就在那台机器上跑[一键安装](../1-getting-started/1.2-installation.md)；容器留给"Gateway只作为别的机器的模型端点"这种场景。

## 怎么跑

没有发布镜像，compose文件会从本仓库的一份检出里构建：

```bash
docker compose up -d
```

Podman读同一个文件：

```bash
podman compose up -d
```

两种方式下：

- 界面在http://localhost:17000。
- SQLite数据库放在一个**`down`之后依然存在的命名卷**里。
- `conf/app.conf`从仓库挂载进去，所以第一次启动前就能改它播种的那些设置，不用重新构建镜像。

## 如果它要服务别的机器

容器通常从宿主机外面就能连上，这正是[5.2](5.2-security-and-network.md)那一节讲的情况：改掉管理员密码，并且每个发往`/v1`的请求都带上中继令牌。
